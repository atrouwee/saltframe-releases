# saltROOM releases

Builds of saltROOM for macOS, and the update feed the app reads.

- **Install:** download the latest `.dmg` from [Releases](../../releases), open it, and drag saltROOM to Applications.
- **Updates:** saltROOM checks `appcast.xml` in this repo once a day (and from saltROOM › Check for Updates…).
  Every build is notarized by Apple and signed with the saltROOM update key; the app refuses anything else.
- **Needs:** macOS 27 on an Apple silicon Mac.

saltROOM is in a private alpha. This repository holds no source code: only the update feed and release notes.
